ПР3. Ответы на контрольные вопросы

1. Чем отличается x += 5 от x = x + 5?

Ничем. x += 5 — это короткая запись x = x + 5. Результат одинаков

2. В чём разница между x++ и ++x?

x++ сначала использует старое значение, потом увеличивает его на 1.

++x сначала увеличивает значение на 1, потом использует новое.

3. Какой тип получается при сравнении?

Всегда получается bool: true или false.

4. Что такое короткое замыкание в && и ||?

Когда программа не проверяет второе условие, если результат уже поняТ

В false && второе условие проверять не нужно — результат всё равно false.

5. Посчитайте 10 - 2 * 3 + 4 / 2.

Сначала умножение и деление:

10 - 6 + 2
4 + 2 = 6
Ответ: 6.

6. Зачем ставить скобки, если они не обязательны?

Чтобы код было проще читать и понимать. Скобки показывают, что нужно выполнить первым.
